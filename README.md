# 🐾 BRACU Animal Adoption System

A database-driven **Animal Management and Adoption System** developed as a project for **CSE370 – Database Systems** at **BRAC University**.

The system is designed to support the management and welfare of animals within the BRAC University community, including **animal adoption, veterinary treatment, donations, and expense management**.

## 📌 Project Overview

The **BRACU Animal Adoption System** provides a centralized platform for managing animals and their related activities.

The system allows users to view animals available for adoption and submit adoption requests. It also keeps track of **veterinary treatments, veterinarians, donations, and expenses** associated with animal care.

Administrators can manage animal records, adoption requests, veterinary information, financial records, and other relevant data through the system.

## ✨ Features

### 🐾 Animal Management

* Add and manage animal records
* Store animal details and information
* Track the current status of animals
* View animals available for adoption

### 🏠 Adoption Management

* Browse animals available for adoption
* View detailed information about animals
* Submit adoption requests
* Manage adoption applications
* Track adoption status

### 🩺 Veterinary Management

* Maintain veterinarian information
* Record veterinary treatments
* Track the medical care provided to animals
* Maintain treatment history for individual animals

### 💰 Donation Management

* Record donations made for animal welfare
* Maintain donor information
* Track donation amounts and dates
* Manage donation records

### 💸 Expense Management

* Record expenses related to animal care
* Track different types of expenses
* Maintain expense amounts and dates
* Monitor spending related to animal welfare

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS
- **Backend:** PHP
- **Database:** MySQL
- **Programming Language:** PHP
- **Database Query Language:** SQL

## 🗄️ Database

This project focuses on applying database concepts to a real-world animal welfare and adoption scenario.

The database manages information related to:

* 🐾 Animals
* 👤 Adopters
* 🏠 Adoption Requests
* 🩺 Veterinarians
* 💊 Veterinary Treatments
* 💰 Donations
* 💸 Expenses
* 👨‍💼 Administrators
* 🐾 Feeding of the animals

The project demonstrates concepts such as:

* Relational database design
* ER modeling
* Primary and foreign keys
* Database relationships
* SQL queries
* CRUD operations
* Data management and integrity

## 🎯 Project Objective

The main objective of this project is to develop a database system that can organize and manage different aspects of animal welfare within the BRAC University community.

The system brings together **animal management, adoption, veterinary care, donations, and expenses** in one platform, demonstrating the practical application of database concepts learned in CSE370.
